# KingCaptcha

A minimal, reusable React component for handling a CAPTCHA-like challenge interface.

## Installation

```bash
npm install king-captcha
```

## Usage

```tsx
import { KingCaptcha } from 'king-captcha';

<KingCaptcha label="Prove you're human" />;
```

## Development

```bash
npm run dev     # Launch local playground
npm run test    # Run tests
npm run build   # Build for distribution
```
